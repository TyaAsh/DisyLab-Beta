# Disy v0.2.0 版本功能与技术说明

## 1. 版本信息

- 产品名称：Disy 无限可能
- 当前版本：v0.2.0
- 产品形态：浏览器端 AI 无限画布
- 目标用户：个人设计师、电商视觉工作者、内容创作者
- 数据模式：本地优先；当前未集成账号、云数据库和多人协作
- 当前版本主题：以文本、参考图、图像生成和资产管理为核心的可视化创作闭环

## 2. 当前已集成功能

### 2.1 无限画布

- 画布平移、缩放、网格背景和小地图。
- 双击或空画布快捷入口创建节点。
- 节点拖拽、选择、框选、复制、粘贴和删除。
- 节点之间可视化连线，支持选中状态和流光反馈。
- 多节点打组、解组、网格排列和组颜色设置。
- 画布名称修改、保存状态提示和本地项目保存。
- 一个项目内支持多画布的新建、切换、重命名、复制和删除；项目之间的数据隔离。

### 2.2 节点类型

- 文本节点：多行编辑、放大编辑、Markdown 工具栏和文本生成。
- 图像生成节点：提示词、模型选择、生成数量、画幅、分辨率和细节等级。
- 上传图片节点：本地图片导入、预览、下载和作为参考图使用。
- 组合节点：容纳多个节点，支持整体保存、下载和恢复。

### 2.3 AI 与 API

- 支持配置多个兼容 OpenAI 风格的 API 连接。
- 从远程 `models` 接口读取模型目录。
- 按文本、图像、视频、音频能力分类和启用模型；当前实际生成链路已接入文本和图像。
- 文本生成使用 `chat/completions`。
- 图像生成使用 `images/generations`。
- API Key 仅保存在当前浏览器会话的 `sessionStorage`，公共连接配置保存在 `localStorage`。
- 提供网络、权限、额度、参数和服务端错误的分类提示。

### 2.4 参考图与生成流程

- 通过节点连线或手动选择添加参考图。
- 提示词编辑器内以内联标签显示引用图片。
- 支持移除引用、避免重复引用和显示引用缩略图。
- 单次可生成多张结果，并在图像节点中保留生成变体。
- 可切换生成结果、放大预览和下载图片。
- 项目级风格参考图、启用开关和全局提示词后缀。

### 2.5 资产库

- 将单节点或节点组合保存为资产。
- 上传本地图片到资产库。
- 新建文件夹、未归档分类、搜索和缩略图尺寸调整。
- 资产可拖回画布，并恢复组合中的节点和连线。
- 支持画廊放大、滚轮/方向键切换、单项下载和删除。
- 支持批量选择、全选、下载和删除。

### 2.6 历史与反馈

- 生成历史记录图片、提示词、模型和文件名。
- 生成历史支持搜索、缩略图尺寸调整、画廊浏览和批量操作。
- 输出历史记录文本/图像请求的成功与失败状态。
- 输出历史显示模型、连接、请求数量、输出数量、错误详情和请求 ID。
- 输出历史按 24 小时保留策略清理。
- 删除操作提供二次确认，常用操作提供 Toast 反馈。

### 2.7 文件与本地数据

- IndexedDB 保存当前画布项目、节点、连线和项目设置。
- localStorage 保存资产库、资产文件夹、生成历史和公开 API 配置。
- sessionStorage 保存 API Key，关闭浏览器会话后不作为长期明文配置保留。
- 支持单图下载和多图目录下载；能力取决于浏览器文件系统 API 支持情况。

### 2.8 Agent 对话工作台

- 从左侧 Disy Logo 打开右侧 Agent 面板，支持新建、切换和删除对话。
- 对话模型和生图模型可在 Agent 会话内独立选择。
- 支持使用 `@` 或“从画布选择”引用已生成或上传的图片，引用显示在输入框中并保持光标位置。
- Agent 可进行多轮脑暴并生成可编辑的图像方案；用户在对话框确认后，才创建图像节点并执行一次生图请求。
- 参考图、提示词、模型、画幅、分辨率和数量会在确认时冻结，避免重复请求。

### 2.9 项目包导入与导出

- 支持 `.disy` 项目包，包含项目、多个画布、节点、连线、资产、文件夹、生成历史、输出历史和 Agent 会话。
- 导出前会处理可归档的本地/远程媒体；导入前校验包结构并以事务方式写入。
- 导出包不包含 API Key、Authorization、Token、密码等敏感信息；导入后需在本机重新配置密钥。

| `vite.config.ts` | Vite 开发服务配置 |

## 5. 当前版本边界

- 没有账号注册、登录和用户权限。
- 没有服务端数据库、云端项目同步和多人实时协作。
- API Key 由使用者在浏览器会话中配置；公开体验站不应内置平台方私密 Key。
- “当前项目”资产/历史筛选尚未建立完整的项目 ID 归属模型。
- 视频和音频模型可以在目录中分类，但当前没有完成视频/音频生成工作流。
- 当前项目采用浏览器端直连外部生成 API，目标 API 必须允许浏览器跨域请求；正式公共产品更建议增加服务端代理。

## 6. 后续版本路线图

### v0.2 计划

- 项目管理：支持新建项目，以及上传、导入已有项目文件。
- 节点搜索：按名称、类型、提示词、文件名和生成内容定位节点。
- 预设系统：
  - 风格化预设。
  - 分镜预设。
  - 人设图预设。
  - 场景设定图预设。
- Skill 添加：为特定创作任务加载结构化工作流与能力说明。

### 后续计划

- Agent 对话式生图：通过连续对话理解修改意图、上下文和参考素材。
- 视频生成：视频模型、首尾帧、参考图、生成任务、预览和资产管理。
- 桌面端应用：增强本地文件访问、离线资产管理与系统级创作体验。
- Web 与桌面端项目互传：支持项目文件导入、导出和双向传递。
- 账号与云同步、项目分享、权限控制和团队协作。
- 服务端任务队列、密钥托管、额度控制和生成审计。

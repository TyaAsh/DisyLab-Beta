## 一、功能总览

### 画布

- 无限画布：平移、缩放、网格、小地图
- 节点：文本 / 图像生成 / 上传图 / 分组
- 连线引用（图1、图2…）、复制粘贴、删除、框选
- 撤销 / 重做
- 节点多时自动性能模式
- 多画布、多项目（新建 / 切换 / 重命名 / 删除）

### AI 生成

- 多 API 连接（OpenAI 兼容）
- 预设：GRS AI、APIYI、GPTGod、OpenAI、硅基流动
- 文本生成、图像生成（含 GRS AI 异步轮询）
- 画幅 / 分辨率 / 细节 / 批量张数
- 参考图、风格预设（调用词 + 参考图）
- 并发生成限制、暂停 / 停止
- Agent 多方案选择后独立确认生成

### 资产与历史

- 资产库（保存、文件夹、搜索、画廊、批量）
- 生成历史（本机归档，减少裂图）
- 输出历史（成功 / 失败、错误详情、失败图找回）
- 运维日志（门禁）：捞任务结果与图片 URL

### 导入导出

- 右上角导入 / 导出入口 + 项目弹窗内入口
- 二进制 `.disy` 完整备份（画布、历史、资产；不含 API Key）
- 导入前自动备份；底部进度提示直到结束

### 其它

- 帮助中心（快捷键与使用指南）
- 品牌 DisyLab，域名 disylab.netlify.app
- 生产构建无 sourcemap；基础防右键 / 防常见查看源码快捷键

## 四、还有哪些高风险

### 高（容易丢图或误伤数据）

1. **临时链接裂图**  
   画布节点若仍是服务商 CDN URL，约数小时后会裂；历史归档失败时更明显。运维日志可捞，但要赶在过期前。

2. **导入会覆盖本机工作区**  
   虽会先自动备份，若用户没拿到备份文件，等于本机数据被替换。

3. **浏览器没图但可能已扣费**  
   中转中断、跨域等问题下仍可能发生；需对照运维日志与服务商后台。

### 中

4. **运维门禁是前端的**  
   挡普通人，挡不住会开 F12 的人；日志也只存在本机浏览器。

5. **超大工作区导入导出**  
   可能很慢或占满内存导致卡死。

6. **本地存储配额满**  
   历史图 / 运维日志写满后，部分保存可能静默失败。

7. **无云同步**  
   清缓存或换设备 = 项目没了，只能靠用户自己导出的 `.disy`。

### 低

8. 本地 `promo/` 宣传物料未入库  
9. 私有仓库下 GitHub Pages 不部署，以 Netlify 为准  
10. Agent 依赖模型按 JSON 格式回复，格式乱时方案卡可能异常

# DisyLab v1.0.0 版本说明

发布日期：2026-08-10

## 本次重点

- 修复新版二进制 `.disy` 项目包被误判为 JSON、导致无法导入的问题。
- 导入前完成格式、结构和媒体完整性校验；结构与历史媒体在同一 IndexedDB 事务内替换，失败时不覆盖原工作区。
- 空工作区直接导入；有内容时可选择备份，连续两次拒绝备份后才允许无备份覆盖。
- 导出支持“全部工作区”和“当前项目及其全部画布”两种范围。
- `.disy` 媒体按相同来源无损去重，避免重复图片多次写入；不进行有损转码，不降低原图分辨率。
- 大项目导入改为分段读取，导出直接拼接 Blob，降低峰值内存占用。
- 项目名全局唯一、同项目下画布名唯一；重名时自动追加数字。
- Agent 在用户明确指定方案数量时按指定数量返回；未指定时默认提供 3 个方案。
- 新建风格预设默认关闭；只有用户主动启用后，调用词和风格参考图才会参与 Agent 与画布生图。
- 文本、图像与上传图片节点的左右“＋”均可唤起引用生成菜单；左侧创建上游节点，右侧创建下游节点，并自动连线。

## 数据完整性

- 当前项目导出会保留该项目、全部画布、Agent 会话、项目历史，以及当前仍为全局共享的资产库和文件夹。
- 导入包缺少被引用媒体时会在写入前停止，当前工作区保持不变。
- 导入前备份若有图片无法归档，会取消导入，避免用户误以为备份完整。
- API Key、Authorization、Token 和密码等敏感字段不会写入项目包。

## 兼容性

- 二进制包继续使用 `DISYLAB1` 格式，兼容此前已经导出的二进制 `.disy`。
- 继续支持旧版 JSON `.disy` / `.json` 工作区快照。
- 导入旧包时会自动规范化重复的项目名和画布名，不改变项目、画布 ID 及引用关系。

# DisyLab 交接文档 · 模型目录增强（2026-08-12）

## 一、本次目标
1. **APIYI 视频模型缺失**：API易（APIYI）的 Seedance 走独立端点 `/seedance/api/v3/...`，标准 `GET /v1/models` 不枚举，导致视频标签下只显示 Veo。
2. **通用化**：把"厂商清单补齐"做成通用注册表，不只针对 APIYI，任何厂商都能声明隐藏模型。
3. **节点编辑器去厂商名**：模型下拉小字由 `{厂商名} · ID: xxx` 改为只显示 `ID: xxx`。
4. **实时拉取 + 自动预勾选**：获取模型后自动勾选公认好用的模型（文本 gemini/gpt、图像 nano/image2），并自动选好默认模型。

## 三、通用厂商模型补齐清单机制
`fetchRemoteModels` 现在按 `VENDOR_MODEL_SUPPLEMENTS` 查找匹配当前 baseUrl 的厂商：
- `catalogOnly: true`（目前仅 GRS AI）：跳过 `/v1/models`，直接用本地清单（GRS proxy 优先，失败回退本地）。
- 其余厂商：先 `GET {baseUrl}/v1/models`，解析后用 `supplementalModels` 中 id 不在 live 结果里的条目补齐、按 id 去重、按 name 排序返回。
- **兜底**：当 `/v1/models` 网络失败或 `!ok` 且存在 supplement 时，直接返回本地 supplement 清单（避免 Ark 这类 `/v1/models` 不存在的厂商完全拉不到模型）。

### 现有清单内容
- **GRS AI**（catalogOnly）：原 `GRSAI_LOCAL_MODEL_MANIFEST`，含 gpt-image-2 系列、nano-banana 系列、gpt-5.x、gemini 系列。
- **APIYI**（video）：`doubao-seedance-2-0-260128` / `-fast-260128` / `-mini-260615`
- **即梦 / 火山 Ark**（video + image）：上述 3 个 Seedance 2.0 + `doubao-seedance-1-5-pro-251215`(video) + `doubao-seedream-5-0-pro-260628`(image)
- **OpenAI 原生**（video）：`sora-2` / `sora-2-pro`

> GPTGod、硅基流动（SiliconFlow）经调研 `/v1/models` 已完整枚举，无需补清单。

## 四、自动预勾选规则
`isModelAutoEnabled(model)`：
- text 能力：`/gemini|gpt/i` 命中、且 id 不带排除后缀 → enabled
- image 能力：`/nano-banana-2|nano-banana-pro|gpt-image-2/i` 命中、且 id 不带排除后缀 → enabled
- video 能力：不自动勾选
- 排除后缀（命中即不勾选）：`-(?:vip|vt|lite|fast|cl|2k|4k)(?:-|$)/i`。即只自动勾选干净基线款（如 GPT Image 2 / Nano Banana 2 / Nano Banana Pro），带 `-vip`/`-fast`/`-4k`/`-cl`/`-2k`/`-vt`/`-lite` 的变体一律不自动勾选。

`pickPreferredModelId(models, kind)`（仅从已 enabled 中选）：
- text：gpt 优先 → gemini → 首个
- image：gpt-image/image2 优先 → nano → 首个

拉取后若全局 `selectedTextModel`/`selectedImageModel` 还未设置，则写入优选模型。已选择则保留，不覆盖用户手动改动。

## 五、实时拉取行为
- 在 API 设置弹窗，baseUrl 与 apiKey **都非空**且当前连接 `draftModels` 为空时，去抖 600ms 自动触发一次 `refreshRemoteModels()`。
- 手动「获取当前连接模型」按钮保留，仍可随时重拉。
- 只要 `draftModels` 非空（已拉过），不再自动拉取，避免覆盖手动勾选。

## 六、已知限制 / 注意事项
1. **视频生成流程未实现**（Roadmap 下一版）：Seedance/Sora 即使显示在视频标签下，目前仍不能实际生成视频（AgentPanel 标注「视频（暂未开放）」）。本次仅解决目录可见。
2. **Ark 的 `/v1/models` 路径**：火山方舟标准模型列表是 `/api/v3/models`，并非 OpenAI 兼容 `/v1/models`。所以走兜底分支返回本地清单——能看到 Seedance/Seedream，但前提是 baseUrl 命中 `*.ark.cn-beijing.volces.com` 正则。若用户配的 Ark 地址 host 不同，匹配不到就不会补齐。
3. **补清单是静态数据**：模型 id 来自官方文档快照，厂商若更新模型 id（如 Seedance 新 snapshot），需手动更新 `src/imageApi.ts` 里的清单。
4. 自动预勾选只在新拉取且未手动选择时生效，不会覆盖既有配置。

## 七、如何新增一个厂商（维护指南）
1. 在 `src/imageApi.ts` 定义该厂商的 `Xxx_LOCAL_MODEL_MANIFEST: RemoteModel[]`（每项 `{ id, name, capability }`）。
2. 在 `VENDOR_MODEL_SUPPLEMENTS` 数组里加一条：`{ match: (url) => /^https?:\/\/(...)(?:\/|$)/i.test(url), supplementalModels: Xxx_LOCAL_MODEL_MANIFEST }`。
3. 若该厂商完全没有 `/v1/models`（如 GRS），加 `catalogOnly: true`。
4. `npm run typecheck && npm run build` 验证。

## 八、连接级启用 / 断开-重连（2026-08-12 第二轮）

用户新增需求：① 连接编辑器新增「断开链接」按钮，断开后不必删除即可「重新链接」；② API 设置可让用户选择启用哪个连接；③ 链接多个厂商时，用户可自由选择启用哪些连接。

### 数据模型（`src/store.ts`）
`ApiConnection` 新增两个可选字段：
- `enabled?: boolean`：连接级总开关，默认 `true`。为 `false` 时该连接的模型不参与任何选择。
- `disconnected?: boolean`：软断开状态，默认 `false`。为 `true` 时 **API Key 保留不清除**，连接与模型从所有模型选择器中隐藏，直到一键重新链接。

新增导出函数 `isConnectionUsable(connection)`：`connection.enabled !== false && !connection.disconnected`。所有「连接是否可用」的判断统一走它。

`readApiSettings` 读取时显式归一化 `enabled`/`disconnected`（缺省分别为 true / false）。`apiConfigured`（store 初始值与 `saveApiSettings` 内）改为 `connections.some(c => isConnectionUsable(c) && baseUrl && apiKey)`，即禁用/断开的连接不计入「已配置」。

### 连接侧边栏（`src/App.tsx`）
- 每个连接卡片改为 `div.api-connection-card` 结构：左为选中按钮 `.api-connection-main`，右为电源开关 `.api-connection-power`（lucide `Power` 图标）。
- 电源开关调用 `toggleConnectionEnabled(id)`：在 `enabled` 的 true/false 间切换，并即时持久化；若切换导致当前选中模型失效，会自动回退到首个可用模型（走 `pickValidSelections`）。
- 连接卡片视觉：禁用时整体 `opacity:.5`；在线圆点仅在「可用且有 Key」时亮绿；断开态小字显示「已断开」。

### 连接编辑器（`src/App.tsx`）
- 标题栏右侧为一组紧凑图标按钮（无文字，含 `title` 提示）：`Unplug`（断开链接，红 `.is-danger`）、`PlugZap`（重新链接，绿 `.is-success`，仅断开态显示）、`Trash2`（删除连接，红 `.is-danger`），并排排列。三个按钮都有悬停反馈（hover 加深颜色+背景）。
  - **断开链接** `disconnectCurrentApiConnection()`：置 `disconnected:true`，**保留 API Key 不清空**；若其模型正被选中则回退；连接状态立即变为不可用（圆点转灰）。
  - **重新链接** `reconnectCurrentApiConnection()`：置 `disconnected:false` 即恢复，Key 已原样保留，无需重填，一键连回。
  - （若用户在断开态下直接点「保存当前连接」且 Key 非空，也会因 `hasKey` 自动 `disconnected:false` 而恢复。）
- 已断开时在编辑器顶部显示蓝色 banner：「该连接已断开，API Key 已保留。点击「重新链接」即可恢复，无需重新填写。」

### 选择聚合统一过滤（`src/App.tsx`）
以下聚合处统一加 `.filter(isConnectionUsable)`：
- `enabledTextModels` / `enabledImageModels`（节点编辑器、欢迎区、Agent 抽屉共用，向下传给 `AgentPanel` 的 `textModels`/`imageModels`）。连接断开或停用后，这些列表立即剔除对应厂商的所有模型，因此节点编辑器与 Agent 对话中都不会再显示。
- `hasCatalogTextModels` / `hasCatalogImageModels`（「尚未启用 / 尚未获取」提示）。
- `saveApi` 与 `toggleConnectionEnabled` / `disconnectCurrentApiConnection` 通过新增模块级函数 `pickValidSelections(connections, previous)` 计算有效选中项（只从可用连接的已启用模型中取，缺省回退首个），避免选中被禁用/断开连接的模型。

### CSS（`src/styles.css`）
- 重写 `.api-connection-list` 卡片相关样式（原 `> button` 选择器改为 `.api-connection-card` / `.api-connection-main` / `.api-connection-power`），新增 `.is-disabled`、`.api-connection-power.is-on`。
- 新增 `.api-detail-actions`、`.api-icon-button`（含 `.is-danger` / `.is-accent` 变体）、`.api-disconnected-banner`；另将 `.api-detail-title` 改为 `align-items:center` 让图标按钮与标题对齐。

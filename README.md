# Disy 无限可能

面向个人设计师、电商工作者和内容创作者的 AI 无限画布 Web 平台。

当前版本已实现文本、图片、上传与组合节点，拖拽连线，文本/图像生成，多 API 连接，本地项目保存，资产库、生成历史、输出历史、图片画廊和批量操作。

## 本地运行

```bash
npm install
npm run dev
```

默认地址：`http://127.0.0.1:1420/`

## 检查

```bash
npm run typecheck
npm run build
```

建议使用 Node.js 20.19+ 或 22.12+。
